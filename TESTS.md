# Результаты функционального тестирования Telegram-бота

Бот предназначен для анализа вакансий с популярных job-платформ и оценки резюме пользователя. Ниже представлены результаты ручного функционального тестирования основных сценариев взаимодействия.

Все 7 тест-кейсов пройдены успешно. Выявленные замечания носят рекомендательный характер и не блокируют базовую функциональность.

---

## Тест-кейсы

| № | Требование | Входные данные | Сценарий | Ожидаемый результат | Фактический результат | Статус | Комментарии |
|---|-----------|---------------|----------|--------------------|-----------------------|--------|-------------|
| 1 | Отображение кнопки "Start" при первом входе | Кнопка "Start" | Пользователь нажимает кнопку Start | Бот отображает сообщение: «Привет! Напиши описание вакансии для анализа:» | Бот отображает сообщение: «Привет! Напиши описание вакансии для анализа:» | ✅ | — |
| 2 | Приём и подтверждение описания вакансии | Текстовое описание вакансии | Пользователь отправляет описание вакансии «Системный аналитик…» | Бот подтверждает получение и предлагает выбрать сайт для поиска | Бот подтверждает получение и выводит кнопки выбора сайта | ✅ | — |
| 3 | Выбор сайта и запуск поиска | Кнопки: hh.ru, rabota.ry, hh1.az, hh.kz, hh.uz, headhunter.ge | Пользователь выбирает hh.ru; отдельно — ввод несуществующей вакансии «ыыыы» на hh.uz | Бот выводит статистику (20 сообщений) + .xlsx файл + предложение проверить резюме; при несуществующей вакансии — «Вакансии не найдены» | Соответствует ожидаемому результату | ✅ | Полное время ответа — ~1 минута |
| 4 | Запрос резюме для анализа | Кнопка «Отправить резюме для анализа» | Пользователь нажимает кнопку | Бот просит прислать резюме в текстовом формате | Бот выводит соответствующее сообщение | ✅ | — |
| 5 | Анализ резюме и расчёт шанса на оффер | Резюме в текстовом формате | Пользователь отправляет резюме | Бот выдаёт оценку шансов, сильные/слабые стороны | Бот выдаёт оценку, сильные/слабые стороны и стратегические советы | ✅ | Рекомендуется добавить поддержку загрузки файла резюме |
| 6 | Валидация при отсутствии выбора хоста | Произвольный текст вместо выбора хоста | Пользователь вводит текст, не выбрав хост | Бот отображает: «Пожалуйста, выберите хост из предложенных» | Бот отображает корректное сообщение | ✅ | — |
| 7 | Доступность всех хостов | Кнопка выбора хоста | Пользователь открывает список хостов | Отображаются все 6 хостов | Все 6 хостов отображаются корректно | ✅ | — |
